Technical Architecture

Clean, Editor-Isolated C# Architecture

CutHot Hierarchy Studio is engineered specifically for production Unity pipelines—combining an isolated Assembly Definition with a unified, zero-allocation IMGUI `EditorWindow` system.

Assembly Definition
.asm

CutHot.HierarchyStudio.Editor.asmdef

Strict Editor-Only Compilation Boundary

Isolates all Hierarchy Studio code strictly to the Unity Editor via "includePlatforms": ["Editor"]. Your standalone builds (PC, Console, Mobile, WebGL) never compile or include a single byte of tool code, ensuring zero runtime overhead and faster script domain reloads. 

{
  "name": "CutHot.HierarchyStudio.Editor",
  "rootNamespace": "CutHot.HierarchyStudio",
  "includePlatforms": [ "Editor" ],
  "autoReferenced": true
}

Custom Row Images & Banners

Attach any project Texture2D across full hierarchy rows to visually mark bosses, managers, or environment zones.

Guarantees crystal-clear readability even over bright or high-detail banner artwork using runtime-baked soft shadow textures and glass containers.

  • ▸ Baked 3-slice feathered shadow behind icons & labels
  • ▸ Configurable smoky glass bars (BarSettings)
  • ▸ Adjustable fill opacity, crisp border width & row gaps
  • ▸ Adapts dynamically to Unity Light & Dark skins

Quick Start Documentation

4-Step Setup & Production Workflow

Get CutHot Hierarchy Studio running in your Unity project in under 60 seconds.

1

Installation & Folder Structure

Place the scripts and assembly definition inside an Editor directory anywhere in your Assets/ folder:

Assets/
└── CutHot/
└── HierarchyStudio/
└── Editor/
├── CutHot.HierarchyStudio.Editor.asmdef
├── HierarchyStudioWindow.cs
└── HierarchyStudioWindow.Part2.cs
2

Opening the Studio Window

Open the control panel from Unity's top menu bar: Tools > CutHot > Hierarchy Studio

Drag and dock the Hierarchy Studio tab right next to your Inspector or below your Hierarchy window for instant styling access while building levels.

3

Styling Rows with Textures & Glass Bars

Select one or more GameObjects in the Hierarchy, assign any Texture2D in the Studio panel, fine-tune Crop / Zoom / L→R Fade, toggle Square Bars and Label Shadow, and click Apply.

4

Choosing Themes & FX Intensity

Browse 102 animated themes across Core, Extra, Elemental, and Action packs. Dial in FX Level (0–5), toggle Always Animate for continuous ambient motion, and add custom Icon Rules for third-party assets.
